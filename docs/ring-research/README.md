## 新增查詢的記錄方式

每份查詢記錄包含問題、結論、來源 URL、來源類型、查核日期，以及適用型號／韌體。原廠規格、其他戒指的社群結果、本戒指實測與產品提案要分別標示。

數字換算須列出公式；未量測的耗電、準確率與延遲標示 `TBD / Needs device validation`。新發現如果修正舊結論，要留下日期與修正原因。

只記錄必要的公開資訊與驗證摘要；個人健康數值、校正檔、附近裝置識別碼、個人設定及完整私人工作階段紀錄留在本機。
