# 戒指滑鼠校正網頁

2026-10-09（Asia/Taipei）。使用者已確認游標會移動，但方向不符直覺，因此新增網頁校正工具。

## 使用流程

1. 啟動 calibration_server.py 或 Start Calibration.command。
2. 本機開啟 http://127.0.0.1:8765，按連接戒指。
3. 依序記錄中立、向右、向上姿勢；每次 3 秒，要求至少 10 筆資料並檢查方向分散度。
4. 將右／上向量投影到中立重力的切平面，透過 Gram matrix 的逆矩陣建立雙方向映射；拒絕太小、過大或近共線的方向。
5. 網頁內游標測試、速度調整、長按暫停、回中心及重新校正。
6. 儲存至本機 calibration.json。ring_mouse.py 載入設定，啟動時仍暫停。
7. 按中斷連線後再啟動系統游標程式，避免兩個 BLE 客戶端重疊。

## 實作邊界

校正頁不產生系統滑鼠或鍵盤事件。後端只監聽 127.0.0.1，檢查 Host／Origin，拒絕外部網站指令；不開啟 CORS。原始感測資料不送至線上入口，個人校正檔不提交至 GitHub。

私人線上入口：https://qring-direction-calibration.george-chen-1104.chatgpt.site 。此入口無法直接存取戒指，只提供本機連結與介面；實際校正使用本機服務。
