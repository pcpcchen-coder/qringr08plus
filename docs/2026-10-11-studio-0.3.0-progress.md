## 尚待完成

- 真實佩戴時的四方向手感、誤觸率、長期連線穩定性與各模式耗電。
- 配戴／取下辨識及充電自動暫停；目前僅查詢研究與提案，不能將充電／接觸狀態當作已實作的游標守門。
- 未解碼健康候選的有效格式及量測準確度；ECG 啟動流程仍未提供。
- 戒指內建心率排程的確實停用；ACK 與讀回不一致，不宣稱關閉所有內部感測。
- 眼鏡、Apple Watch、戒指與 iPhone 的跨裝置 AI 整合。
- GitHub Release 二進位安裝包；此交付先完整保存原始碼、測試、建置方式與進度。

研究與來源見 [戒指查詢索引](ring-research/README.md)，跨裝置構想見 [貼身 AI 助理藍圖](wearable-ai/README.md)。

## 接手方式

先讀 [App README](../mac-app/README.md)，依 [M6 指南](M6-HANDOFF.md) 在 Apple Python 3.9 venv 執行 Python／Node 測試與建置，再執行封裝 App 的 `--self-test`。建置產物位置與二進位交付狀態見 [產物說明](../releases/README.md)。

公開交付只含程式與必要的功能驗證摘要；個人健康數值、校正、偏好設定與完整私人收發紀錄不提交。
