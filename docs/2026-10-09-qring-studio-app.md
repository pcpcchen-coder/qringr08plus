# QRing Studio 0.2.0 驗證紀錄

日期：2026-10-09，Asia/Taipei。

## 裝置與已驗證資訊

裝置 R08_E703，硬體 RT08_V3.1，韌體 RT08_3.10.48_260309。電量與充電狀態的 0x03 查詢正常，GATT 裝置資訊及 0x3C 能力位元可讀取。

心率（0x69 type=1）與血氧（type=3）均得到 err=0、非零值，随后送出停止。這只證明裝置回報，未驗證醫療準確度。本文件與公開 Repo 不收錄個人的實際數值或原始健康封包。

血壓、疲勞、綜合檢查、即時心率、壓力、血糖、HRV：每項約 12 秒單次探測有進度回應，但沒有已解碼有效值。體溫首次探測前 BLE 斷線，重新連線後完成 12 秒探測，亦有回應但無已解碼有效值。短時間未收斂不等於不支援。

其他唯讀查詢中，內建量測排程、通知路由、個人設定、溫度單位、目標、久坐／飲水提醒、當日活動、心率／HRV／壓力／步數歷史、ping 與替代版本通道有回應，部分回覆為結束／無資料標記；沒有誇大為完整歷史解碼。睡眠歷史、資料分佈、0x76 省電、0x6C ECG 設定、抬手顯示查詢被拒絕；血壓歷史與 ring 手勢喚醒查詢未回應。這些結論只針對該次具體請求。

## 排程備份與還原

0x16 心率排程關閉回覆 ACK，但讀回仍是原設定，界面標示無法確認停止。其他已接管的血氧、壓力、HRV 排程暫停結果可確認，斷線後四項的原值讀回匹配。血壓／體溫及未知排程沒有被宣稱已停止。

## 軟體驗證

- 10 項合成 unit/API 測試通過；測試不發送真實游標或健康量測指令。
- 真實戒指連線、各項探測與原始收發記錄通過。
- App bundle 內建 Python 啟動 API 的 native self-test 通過，不依賴外部 Python。
- ad-hoc codesign 與完整 bundle 驗證通過。
- 已將使用者既有五步校正遷移至個人 Application Support，未包進公開程式或安裝檔。
- App 預設不連線、不啟用滑鼠、不啟動持續量測；手動連線時只做初始資訊與排程管理。

## 本版限制

原生 GUI 自動操作未獲工具授權，因此實際勾選、App 專屬藍牙／滑鼠權限與長時間使用仍需使用者驗證。BLE 斷線會停止 App 任務並顯示錯誤，本版不自動重連或自動重啟滑鼠。無 Intel 版本，未經 Apple 公證，只在目前 Apple Silicon macOS 27.0.1 測試。
