# 觸控回饋與健康候選結果介面

最新進度：本文件記錄當日驗證經過；所述開發成果已納入 0.3.0 原始碼交付。最新狀態與限制見 [0.3.0 進度](2026-10-11-studio-0.3.0-progress.md)。
日期：2026-10-10（Asia/Taipei）。

## 變更

觸控區原先只顯示最後的手勢名稱，重複長按時文字不變。現在每個有效事件都有獨立序號、同手勢次數、接收時間與控制結果；介面短暫亮起，列出最近六筆事件。WebSocket 提供即時更新，一秒狀態更新作為後備。既有 0.5 秒控制防重複規則仍保留，事件回饋不會因此被隱藏。

健康候選區現在為每項測試顯示等待、進行中、完成、逾時、停止或失敗狀態，並顯示本次讀值、接收筆數、更新時間與測試歷時。最近三筆原始數值直接顯示，最近六筆完整封包可展開。新測試開始時建立獨立結果，不以舊測試的數值充當本次結果；結束或逾時後仍保留已收到的資料。

目前未確認格式的健康候選保持「原始值／未解碼」標示，顯示回應碼與原始欄位，不自行換算為血壓、血糖、HRV 或體溫等健康單位。ECG 啟動仍不可用。其他量測類型的自發通知不會提前結束正在測試的項目。

主頁以介面內容雜湊為 JS/CSS 加入版本網址，避免 WKWebView 沿用舊介面快取。

## 驗證

- 19 項 unit/API 測試通過：包括重複長按的獨立回饋、原始讀值與完成封包保留、重試不沿用舊值、逾時與失敗、其他量測通知隔離及資源版本網址。
- 獨立測試服務以合成資料驗證瀏覽器中的重複觸控更新、候選測試等待與結束、原始數值保留、重新測試清除舊值；未使用此服務連接真實戒指。
- App 內建服務 self-test、完整簽章與安裝檢查通過。
- 個人校正檔保留，更新前 App 使用 ZIP 封存於 `releases/QRing-Studio-before-feedback-20261010.zip`，不新增可索引的同名 App。
- UI 驗證圖使用合成資料，保存在 `releases/ui-checks/`；不包含個人健康數值。
- 安裝版原生介面確認載入新增的事件回饋。系統授權曾仍對應舊版簽章，已從系統設定移除失效項目、加入目前安裝版，確認授權符合新版簽章；完整重啟後服務回報控制權限可用。未直接修改 macOS 權限資料庫。

上述開發變更已納入 0.3.0 原始碼交付。健康候選數值的生理意義與準確度仍未驗證。

## 可調觸控防重複間隔

新增 0–2 秒的滑桿與數字輸入，步進 0.01 秒；按「套用並儲存」立即套用，0 秒關閉防重複，預設與一鍵恢復值為 0.5 秒。設定以原子更新保存至個人 Application Support 的 `preferences.json`，重新開啟只沿用間隔，不自動啟用游標、點擊或量測。

22 項測試通過，新增可調間隔與邊界、關閉防重複、設定保存與無效值不覆寫的檢查。原生介面亦驗證輸入 0.25 秒後能儲存並顯示目前套用值，完整重啟後仍保留 0.25 秒；測試完以介面一鍵恢復預設 0.5 秒。更改此設定不會中止正在進行的手動健康測試。更新後控制授權確認可用，並恢復使用者原本勾選的觸控、加速度及電量觀察。
